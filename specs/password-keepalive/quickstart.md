# Feature Quickstart：站点密码保活

## 1. 目标

- 为已保存网页登录账号密码的 HTTPS 站点提供可选的自动会话恢复，不把密码、JWT 或 Cookie 暴露给 renderer。

## 2. 核心文件

- `src/main/storage.ts`：加密站点配置与保活状态。
- `src/main/index.ts`：令牌刷新、自动登录、挑战移交与冷却控制。
- `src/renderer/src/App.tsx`：站点设置中的保活开关与状态。

## 3. 开发步骤

1. 保存站点账号和密码，并显式开启“令牌失效时自动重新登录”。
2. 保持现有刷新令牌优先；仅在会话失效后启动隔离授权窗口。
3. 对验证码、2FA 或风控页显示窗口，等待用户完成验证并自动捕获新会话。

## 4. 验证方式

- 自动化：`npm run verify`。
- 手工：在桌面端新增或编辑 HTTPS 站点，检查无凭据时开关禁用、凭据齐全后可启用，以及手动重授权和清除凭据仍可用。
