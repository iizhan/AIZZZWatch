# Release Notes - 0.1.0

## 基本信息

- 版本：`0.1.0`
- 发布分支：`release/0.1.0`
- 来源分支：`feature/sub2api-monitor`
- 目标主干：`main`
- 标签：`v0.1.0`
- 日期：`2026-07-23`

## 本次发布内容

- 新增：macOS 桌面监控工具，支持三方来源与自有聚合站分离、实时余额/分组/倍率监控、分类价格榜、分组变化历史、菜单栏、置顶和气泡窗口。
- 新增：Sub2API、NewAPI、自动检测与自定义只读映射；聚合站账号、分组、渠道、平台、用量、成本保护和收益归档工作区。
- 新增：MIT 许可证、中文 README、演示截图、开源隐私检查清单与用户授权公开的赞助收款码。
- 调整：本机站点配置、令牌、Cookie、登录账号密码、余额、用量、私有截图与临时数据全部排除在公开仓库之外。

## 验证结果

- 自动化验证：`npm run verify` 通过，含 TypeScript 检查、12 个 Vitest 文件和 168 项测试、Electron 生产构建。
- 打包验证：`npm run package:mac` 成功生成 `AIZZZWatch.app`；`codesign --verify --deep --strict` 通过；zip 完整性检查通过。
- 发布资产：`AIZZZWatch-v0.1.0-darwin-arm64.zip`，约 187 MB，SHA-256：`7f8d7e7bf28d3f8e505e2c171186e46e27a444e8ae1d236c2029bcf28d374a20`。
- 手工验证：README 与验证截图均人工复核为演示数据；未打开或导出正式 Electron userData。
- 未覆盖项：在线 `npm audit` 因当前环境网络审批超时未能完成；发布后需在可联网环境补跑。

## 升级与兼容

- 是否需要迁移动作：不需要。首发且本地配置与偏好保存在独立 userData 目录。
- 对旧产物是否有影响：无公开旧版本。现有本地用户可继续使用已有配置；仓库不含任何配置导出。
- 已知限制：仅 macOS Apple Silicon（arm64）；ad-hoc 签名且未公证；首次打开可能需要在 macOS 隐私与安全中手动放行；Windows、自动更新和安装器尚未提供。

## 风险与后续

- 剩余风险：二开站 API、风控和会话策略可能改变；未公证应用有系统放行提示；在线依赖漏洞审计待补。
- 发布后观察点：下载包的解压、首次打开、菜单栏/置顶/气泡窗口、常用 Sub2API 读取兼容与会话过期后的重新授权。
- 后续计划：补齐 Windows 版本、Developer ID 签名/公证、可选自动更新，以及更多二开站适配模板。
