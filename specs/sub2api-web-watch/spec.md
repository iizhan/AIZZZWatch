# Sub2API Web Watch

功能标识：`sub2api-web-watch`
基线：官方 Sub2API `v0.1.165`（`e9a58c1cb8b5ef626a75c93b4d953fde5e67aa29`）
任务通道：controlled
需求版本：v3（用户已确认）
状态：executing

## 目标

在官方 Sub2API Web 管理端增加可独立升级的 Watch 模块，复用现有管理员认证、分组倍率、渠道模型价格、渠道监控和系统升级能力，提供：

1. 上游账号/渠道聚合检测与健康状态；
2. 聚合排价预览，选择最低价且健康的上游；
3. 自动调价，支持分组倍率 `最低合格倍率 + 0.01` 和模型渠道价格两种模式；
4. 站点、令牌、上游账号保活检测；
5. 预览、确认、审计、冻结和回滚，避免异常上游触发降价。

## 业务规则

- 默认只读预览；自动写入必须由管理员显式启用。
- 仅纳入健康、授权有效、检测时间未过期且余额/配额满足阈值的上游。
- 无合格候选、检测过期、授权失败、余额不足或价格解析失败时冻结当前价格，不自动降价。
- 分组倍率模式：目标倍率 = 最低合格上游倍率 + `0.01`。
- 模型渠道价格模式：目标模型价格 = 最低合格上游模型价格 + `0.01`，具体币种/计费单位沿用现有渠道定价结构。
- 两种模式互斥，默认分组倍率模式，防止两个价格层级互相覆盖。
- 每次检测、候选选择、写入、冻结、回滚都记录最小化审计信息，不记录密钥、完整响应或令牌原文。
- 保活检测使用有界超时、指数退避和最大重试次数；不会无限轮询。
- 官方升级仍由现有 `/admin/system/check-updates`、`update`、`rollback` 流程负责；Watch 表和接口必须在升级失败时可安全回滚。

## v3 完整能力迁移事项与验收

### ITEM-301：完整智能运营信息架构

- 验收：智能运营包含运营总览、上游站点、运营资产、价格排行、聚合排价、自动调价、保活中心、账号关联、成本保护、收益核算、变动记录、任务告警和接入诊断；官方用户、账号、分组、渠道和用量数据不复制为第二套真值。

### ITEM-302：上游站点与安全凭据

- 验收：支持 Sub2API、NewAPI 和受约束自定义兼容站；凭据使用服务端现有 SecretEncryptor 加密，API、日志和审计不返回原文；外部请求有 URL/SSRF 校验、超时和响应体上限。

### ITEM-303：采集、保活与健康真值

- 验收：后台 Runner 支持独立周期、并发上限、防重入、超时、有限退避、重启恢复和优雅停止；价格候选只使用未过期且连续检测合格的观测。

### ITEM-304：真实价格排行与聚合排价

- 验收：排行来自外部上游观测而非本机售卖分组替代数据；支持分类、模型、平台、价格组件、倍率/充值比例和可用状态筛选；无合格候选明确冻结。

### ITEM-305：双模式自动调价

- 验收：分组倍率和模型渠道价格均按最低合格候选 `+0.01`；预览、人工应用、自动执行分级开放；写入通过官方 GroupService/ChannelService，使用当前值前置条件、幂等键、审计和回滚。

### ITEM-306：账号关联与成本收益

- 验收：上游 Key 原文只在服务端检测期间临时比对；歧义不猜测；支持账号成本类型、内部用户、公益分组、历史成本观察、区间收益和数据覆盖状态。

### ITEM-307：变动、任务与告警

- 验收：记录价格新增/删除/涨跌、检测和调价任务结果、冻结原因及告警状态；Web 站内状态替代 Electron 原生通知。

### ITEM-308：官方升级和 Docker 兼容

- 验收：Watch 使用独立表、增量 API 和最小接入点；官方 v0.1.165 基线构建、迁移、测试和 Docker 回退演练通过；关闭 Watch 不影响官方管理和网关流量。

## v1-v2 已完成底座

### ITEM-001：Watch 后端模块与独立数据

- 验收：Watch 表使用 `watch_` 前缀；migration 可重复执行；Wire 启动可用；核心 Sub2API 服务无业务侵入。

### ITEM-002：健康检测与聚合排价预览

- 验收：管理员可查看上游健康、最后检测时间、失败原因；预览只返回候选和冻结原因，不写入目标价格；过期/失败候选被排除。

### ITEM-003：自动调价与审计回滚

- 验收：两种互斥模式可切换；目标值按 `+0.01` 规则计算；启用前有确认；写入失败不做乐观更新；可查看审计并回滚到上一次已确认值。

### ITEM-004：保活检测

- 验收：站点、令牌、上游账号均有检测入口和定时任务；检测有超时、重试上限、退避和停止状态；销毁/重启不遗留无限任务。

### ITEM-005：Web 页面、升级兼容与交付

- 验收：新增 Watch 管理页面和侧边栏入口；`v0.1.165` 构建、前后端测试通过；官方升级路径演练可回滚；生产部署前不自动写价。

### ITEM-006：智能运营信息架构（v2）

- 验收：新增可折叠的“智能运营”一级菜单；当前已实现能力拆分为“运营概览”和“聚合排价”子菜单；所有页面复用官方 `AppLayout`，保持侧边栏、顶部栏和移动端导航；旧 `/admin/watch` 地址兼容跳转到运营概览。
- 约束：未完成的自动调价、保活检测和调价记录不显示空菜单，功能完成后继续挂载到“智能运营”目录。

## 非目标

- 未经独立生产发布确认不修改生产服务器、生产数据库数据或生产价格；不自动执行远程升级。
- 不重写官方分组、渠道、调度和渠道监控核心逻辑。
- 不接入支付、计费、第三方密钥托管或无限制后台任务。
- 不把 Electron 的气泡、置顶、托盘和窗口模式迁入 Web。
